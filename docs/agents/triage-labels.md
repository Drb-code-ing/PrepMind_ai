# Triage Labels

本地 tracker 使用 Matt Pocock skills 的默认角色标签：

| Canonical role | Label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 合同完整，可以实现 |
| `ready-for-human` | `ready-for-human` | 需要人工执行 |
| `wontfix` | `wontfix` | 不处理 |

实现完成后，ticket 状态追加 `done`，并在对应验收文档记录证据等级。
